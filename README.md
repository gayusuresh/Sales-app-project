# Counselor FAQ Desk (React + Vite)

FAQ app for sales counselors: FSD-MERN, Agentic MERN, Data Analytics, Data Science, Playwright, Software Testing.

## Run
```
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
npm run preview
```

## Customize
Edit English in `src/faqData.js` and Tamil in `src/faqTamil.js` and Malayalam in `src/faqMalayalam.js` (same order in all three). Replace every [bracketed] value (fees, duration, EMI, refund policy, batch timings).
Add a question: add one object to EN in faqData.js AND one at the same position in faqTamil.js and faqMalayalam.js.
